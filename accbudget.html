Projection PSA

Construction du Budget

Le budget est construit à partir des données de l'année précédente.

1. Réel N-1

Les données sont récupérées dans la page Réel N-1.

2. Projection PSA

Ces données sont injectées dans la page Projection PSA.

  • réel N-1
  • nombre de jours ouvrés
  • année cible active

3. Génération du Budget

La projection est exportée et devient le budget de l'année active.

4. Ajustement manuel

  • ajouter des clients
  • supprimer des clients
  • renommer des clients
  • modifier les montants projetés

5. Export final

Le budget final est exporté et utilisé dans toutes les vues :

  • reporting
  • évolutions
  • analyses
  • réel vs budget

Les étapes doivent être répétées pour :

PSA • Gueudet • Ford • Clients Directs
